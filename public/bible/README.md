# Bíblia integrada — Revival

66 livros do cânon protestante, Gênesis a Apocalipse, em JSON por livro. Textos Almeida 1819 (Bíblia Livre), declarados em domínio público pela fonte midvash/bible-data. Fonte: https://github.com/midvash/bible-data/tree/main/versions/pt/almeida-livre

O conteúdo é servido localmente pelo aplicativo. O versículo do dia é escolhido por data e lido de /bible/{livro}.json, sem API externa.

Nota: avisos da API Notification neste protótipo funcionam apenas enquanto o site está aberto. Para notificações em segundo plano, implementar push subscription, service worker e agendador no backend.
