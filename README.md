# Revival Front 💜

Frontend de rede social inspirado na nostalgia do Orkut, desenvolvido com React, TypeScript e Vite.

## Executar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Funcionalidades

- Feed com publicações e curtidas
- Perfil editável
- Mural de recados
- Amigos e comunidades
- Depoimentos
- Busca e layout responsivo
- Persistência local usando localStorage

Projeto demonstrativo sem backend, autenticação ou dados reais de outros usuários. Não afiliado ao Orkut.
